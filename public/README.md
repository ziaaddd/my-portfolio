# Static Assets Directory
This directory is served directly by Next.js at the root URL path.

- Place your CV file here named `resume.pdf` -> Available at `http://localhost:3000/resume.pdf`
- Place project screenshots in `public/images/projects/` -> Available at `/images/projects/your-image.png`
- Place your profile photo in `public/images/avatar/` -> Available at `/images/avatar/your-photo.jpg`
